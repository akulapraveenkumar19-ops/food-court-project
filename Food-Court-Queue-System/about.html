Project Overview & Purpose

The Food Court Queue Management System is a modern web-based simulation and operations platform engineered exclusively using client-side technologies: HTML5, CSS3, and modern JavaScript (ES6+).

In traditional food courts and campus cafeterias, physical queues create congestion, order mix-ups, and long customer wait times. This application streamlines the entire customer flow from digital menu discovery to checkout, automated token generation, real-time queue tracking, and kitchen display updates.

No Backend Server

Runs 100% in any modern browser without Node, Python, or PHP setup.

LocalStorage Storage

Stores foodCart, orders, queue, tokenNumber, and orderHistory.

Pure Queue DS

Implements FIFO (Enqueue, Dequeue, Peek, IsEmpty, Size).

Cross-Tab Sync

Admin actions update customer queue displays in real-time.

Computer Science Concept

Queue Data Structure (FIFO) Implementation

A Queue is a linear data structure that follows the First-In, First-Out (FIFO) principle: the first customer to place an order is the first customer whose order is prepared and served.

enqueue(item)

Adds a newly confirmed customer order to the rear of the queue.

dequeue()

Removes and returns the customer at the front of the queue upon order completion.

peek()

Inspects the front customer order without modifying or removing it from the queue.

isEmpty() & size()

Checks if queue has orders and provides current count for estimated wait calculation.

// Queue Implementation used in js/queue.js class Queue { constructor(items = []) { this.items = [...items]; } enqueue(item) { this.items.push(item); } dequeue() { return this.items.shift(); } peek() { return this.items[0]; } isEmpty() { return this.items.length === 0; } size() { return this.items.length; } }
